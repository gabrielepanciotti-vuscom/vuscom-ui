# Backlog — vuscom-ui

Il backlog vero sono gli issue. Qui stanno solo le query e i temi non ancora scomposti.

## Query
- Tutto aperto: `gh issue list --state open`
- Prioritario: `gh issue list --label priority:P1`
- Per area: `gh issue list --label domain:componenti` (o `segnalazioni-utenti`, `rilascio`)

## Temi non ancora scomposti in issue
- Il tester `vuscom-ui-conformita` lanciato sul repo stesso dà avvisi/blocchi su `src/`: da decidere se escludere la libreria o ignorarli.
